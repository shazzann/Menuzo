For Menuzo, I would make **the miniature previews and the full-size editor use the same underlying rendering components**.

This matters because when you create a theme in the Company Admin Panel, its appearance should remain consistent across three places:

**Company Admin Theme Editor → Theme Library Card → Customer Theme Selection**
