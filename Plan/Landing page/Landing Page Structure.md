# Design Direction

* **Style:** Premium SaaS, minimalist, modern.
* **Spacing:** Large vertical spacing (96–140px between sections).
* **Corners:** 20–28px rounded cards.
* **Shadows:** Soft and subtle.
* **Animations:** Fade, slide-up, hover lift, parallax accents, count-up numbers, phone/mockup transitions.
* **Color system:** Match Menuzo's existing orange-accent brand with clean neutrals.
* **Responsiveness:** Design mobile-first; every section should gracefully stack on smaller screens.

This structure is comprehensive enough for an MVP while being extensible as Menuzo grows into a full restaurant platform.
